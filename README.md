# Protego Manager Training

The Protego Protection training portal: https://teond1090.github.io/protego-training/

- `index.html` — the portal: home, training, documents, FAQ and support. One file, no build step.
- `documents/protego/` — every Protego document as supplied: the Word original, a PDF,
  and a page image of each page for the in-page preview. Protego is the only brand: the
  Pre-Launch and Transition letters named a storage operator in four sentences, which
  now use the same [Facility Name] placeholder as the other letters. Nothing else changed.
- `media/` — the Protego logo, rebuilt as a horizontal lockup from the logo in the addendum.

Every rate, rule and deadline on the portal is taken from the Protego documents — the
plan terms, the $14 addendum and the tenant letters. Where they disagree, the plan
terms win.
